# События января

## План мероприятий

- **10 января** — планирование задач на месяц.
- **15 января** — встреча команды по текущему статусу проекта.
- **20 января** — проверка документации.
- **25 января** — подведение промежуточных итогов.

## Цель

Согласовать планы команды и определить приоритеты на начало года.
